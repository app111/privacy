支持 / Support

牛牛浏览器（NiuNiu Browser）· 适用于版本 1.1

这是一款把数据留在自己手机上的浏览器。遇到问题先看下面的清单，多数情况可以在应用内解决。

一、常见问题

广告过滤把正常内容拦掉了怎么办？
浏览页右上角盾牌 → 广告拦截详情 → 关闭「广告过滤」即可放行本页。想长期只拦某类域名，可在同页添加自定义拦截域名（会员功能）。
「本页拦截」显示 0，是不是没生效？
不一定。计数只统计命中广告域名的资源加载失败，页面本身没有这类请求时就是 0，可对照「累计拦截」确认规则在工作。
网页视频调不出播放器 / 倍速没反应？
播放器只在检测到 HTML5 <video> 时出现。使用自研播放内核或 DRM 加密流的站点（部分长视频站）无法接管，这是系统 WebKit 的限制。
清晰度为什么只有部分视频能选？
清晰度只对 HLS 自适应流（m3u8）有意义，iOS 侧能控制的是峰值码率上限；单文件视频没有可切换的变体，这时面板就不显示。
下载中断了会重新下吗？
不会。下载支持断点续传：切到后台会自动暂停，回到应用自动继续；手动暂停后可从断点接着下。
私密空间忘了面容 / 换机怎么办？
可用设备密码进入。文件与钥匙串密钥都只在本机，不提供云端备份或找回，卸载应用或恢复出厂会永久丢失，请先移出重要文件。
无痕标签真的不留痕迹吗？
不写浏览历史；无痕标签使用独立的非持久站点数据，关闭标签即连同 Cookie 与缓存一起丢弃。书签只有你手动点「收藏」才会保存。网站侧仍能通过它自己的日志识别访问，这不在本应用可控范围内。
为什么没有小说、资讯入口？
本应用不内置任何内容源。主页的「小说」入口只有在你自己填写第三方 H5 网址后才会出现，内容由该网站自行提供。

二、会员与订阅

  • 会员解锁的能力只有一项：自定义拦截域名（最多 100 条）。其余功能全部免费。
  • 取消或管理订阅：iPhone「设置 → Apple ID → 订阅」。
  • 换设备或重装后恢复购买：应用内「会员中心 → 恢复购买」，用同一个 Apple ID 即可。
  • 退款由 Apple 处理，请在 reportaproblem.apple.com 提交。

三、反馈时请一并说明

  • 版本号（设置 → 关于）与机型、iOS 版本。
  • 出现问题的网址（如果方便公开）和具体表现。
  • 是否只在某个网站出现，还是所有页面都这样。
