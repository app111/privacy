🛡️ 隐私政策

免费小说 · FreeNovel · v1.2 · 最后更新：2026 年 8 月 14 日

📌 一句话总结

我们不收集你的任何个人身份信息。阅读数据只存储在你的设备中。使用 AI 功能时，章节文本会发送至智谱 GLM 服务器生成分析结果，但不关联任何个人身份。

1. 我们收集哪些信息？

❌ 不收集的信息

  • 不收集姓名、手机号、邮箱、身份证等个人身份信息
  • 不要求注册账号，不提供登录功能
  • 不收集设备 IDFA、IDFV、MAC 地址、精确地理位置
  • 不嵌入任何第三方统计 SDK（如友盟、Google Analytics、Firebase、Adjust 等）
  • 不嵌入任何广告 SDK（穿山甲、AdMob、GDT 等）
  • 不追踪你的阅读行为、不建立用户画像
  • 不上传你导入的本地书籍（TXT/EPUB/PDF）到任何服务器

📱 仅在设备本地存储的数据（不离开你的手机）

  • 书籍元数据：书名、作者、文件大小、导入时间（存入本机 SwiftData）
  • 阅读进度：当前章回、页码、滚动位置（存入本机 SwiftData）
  • 书签与笔记：你添加的书签、划线、5 色高亮、文字笔记（存入本机 SwiftData）
  • 阅读偏好：主题、字号、行距、翻页方式（存入 UserDefaults）
  • 本地书籍文件：通过 WiFi / 分享 / iTunes 导入的电子书，存在 App 沙盒 Documents 目录
  • AI 免费额度计数：每日已使用次数（存入 UserDefaults，自然日重置）

* 你可以在 iOS「设置 → 通用 → iPhone 存储空间 → 免费小说 → 删除 App」来一次性删除所有本地数据。

2. AI 智能功能的数据处理

ℹ️ 本应用内置 AI 智能导读功能（章节导读、人物分析、词义释义、AI 翻译），由智谱 GLM（open.bigmodel.cn）提供技术支持。

📤 使用 AI 功能时，什么数据会被发送？

  • 章节文本内容：你当前阅读的章节正文（截取前 8000 字），用于生成导读、人物分析或翻译
  • 书名与章节标题：用于 AI 理解上下文（如"红楼梦 · 第十四回"）
  • 选中的文字：使用"词义释义"时，你选中的具体文字及其上下文

🔒 数据如何被处理？

  • 数据通过 HTTPS 加密传输至智谱 GLM 服务器（open.bigmodel.cn）
  • 请求中不包含任何个人身份信息（无用户 ID、无设备 ID、无账号）
  • AI 生成的结果返回后显示给你，同时缓存在本机内存中（重启 App 后清除）
  • 我们使用的 GLM-4-Flash 模型不保留用户输入数据用于训练

⚠️ 请注意：使用 AI 功能时，章节文本会经过智谱 GLM 服务器处理。如果你不希望任何文本离开设备，请不要使用 AI 导读功能，基础的阅读、书签、笔记功能完全离线，不受影响。

智谱 GLM 的隐私政策请见：open.bigmodel.cn/user/privacy

3. WiFi 传书功能如何工作？

当你开启「WiFi 传书」时，App 会在你的手机上启动一个仅局域网可访问的 HTTP 服务器（端口 8888）。

  • 🔒 该服务器只监听同一 Wi-Fi 下的连接，不会暴露到公网
  • 📤 你上传的书籍文件直接写入 App 沙盒，不经过任何中间服务器
  • 🚪 关闭页面或退出 App 后，服务器立即停止，不会后台常驻

4. 公版书城的网络请求

「公版书城」展示的书籍元数据（书名、作者、分类、封面）已随 App 安装包一起打包（books.json）。

  • 点击「下载」时，App 会直接从 Project Gutenberg 官方服务器（gutenberg.org / aleph.gutenberg.org）下载公版书籍文件（EPUB / TXT）。
  • 此过程为标准 HTTP/HTTPS 请求，不携带任何用户标识。Gutenberg 的隐私政策请见：gutenberg.org/policy/privacy

5. 应用内购买（IAP）数据处理

本应用提供「AI 会员」订阅服务（月度 / 年度 / 终身），通过 Apple StoreKit 2 框架完成购买。

  • 所有购买交易由 Apple App Store 处理，我们不经手任何支付信息
  • 订阅状态通过 StoreKit 2 的签名验证机制读取，仅用于解锁 AI 功能
  • 我们不收集、不存储任何信用卡、支付账户信息
  • 购买记录由 Apple 管理，可在「设置 → Apple ID → 订阅」中查看/取消

6. 儿童隐私

本 App 不面向 13 岁以下儿童设计，也不会故意收集 13 岁以下儿童的任何信息。由于我们不收集任何个人身份信息，因此不存在儿童数据泄露风险。

📌 TL;DR

We don't collect any personally identifiable information. Reading data lives only on your device. When using AI features, chapter text is sent to Zhipu GLM servers for processing — but is never linked to your identity.

1. What We Collect

❌ Things we NEVER collect

  • No name, phone, email, or government ID
  • No account system — no sign-up, no login
  • No IDFA, IDFV, MAC address, or precise geolocation
  • No third-party analytics SDKs (no Umeng, Google Analytics, Firebase, Adjust…)
  • No ad SDKs (no Pangle, AdMob, Tencent Ads…)
  • No reading-behavior tracking, no user profiling
  • Your locally imported books (TXT / EPUB / PDF) are never uploaded anywhere

📱 Data stored locally on your device only

  • Book metadata — title, author, file size, import date (SwiftData)
  • Reading progress — current chapter, page, scroll position (SwiftData)
  • Bookmarks & notes — bookmarks, highlights in 5 colors, inline notes (SwiftData)
  • Reader preferences — theme, font size, line height, page-turn style (UserDefaults)
  • Book files — imported e-books live in the App's sandbox Documents folder
  • AI free quota counter — daily usage count (UserDefaults, resets each calendar day)

* To wipe everything: iOS Settings → General → iPhone Storage → FreeNovel → Delete App.

2. AI Feature Data Processing

ℹ️ This app includes AI-powered features (chapter guide, character analysis, word explanation, translation) powered by Zhipu GLM (open.bigmodel.cn).

📤 What data is sent when using AI features?

  • Chapter text content — the text of your current chapter (first 8,000 characters), used to generate guides, analysis, or translations
  • Book title & chapter title — for AI context understanding (e.g., "Dream of the Red Chamber · Chapter 14")
  • Selected text — when using "Word Explanation," the specific text you selected and its surrounding context

🔒 How is the data handled?

  • Data is transmitted via HTTPS to Zhipu GLM servers (open.bigmodel.cn)
  • Requests contain no personally identifiable information (no user ID, no device ID, no account)
  • AI results are returned and displayed to you, cached in device memory only (cleared on app restart)
  • The GLM-4-Flash model does not retain user input data for training

⚠️ Please note: When using AI features, chapter text is processed by Zhipu GLM servers. If you prefer no text to leave your device, simply avoid the AI guide features — core reading, bookmarks, and notes work fully offline.

Zhipu GLM privacy policy: open.bigmodel.cn/user/privacy

3. How WiFi Transfer Works

When you turn on "WiFi Transfer", the App starts a local-network-only HTTP server on your phone (port 8888).

  • 🔒 Accessible only on the same Wi-Fi — never exposed to the public internet
  • 📤 Uploaded books go straight into the App sandbox — no intermediate servers
  • 🚪 Server stops immediately when you close the page or quit the App

4. Public Domain Store Requests

Book metadata in the Store is bundled with the App (books.json) — no network fetch needed to browse.

  • When you tap "Download", the App directly fetches the EPUB / TXT from Project Gutenberg's official servers (gutenberg.org / aleph.gutenberg.org).
  • Standard HTTPS only, no user-identifier headers. See Gutenberg's privacy policy at gutenberg.org/policy/privacy.

5. In-App Purchase Data

This app offers an "AI Premium" subscription (Monthly / Yearly / Lifetime) via Apple StoreKit 2.

  • All purchases are processed by the Apple App Store — we never handle payment information
  • Subscription status is read via StoreKit 2's signed verification, used only to unlock AI features
  • We do not collect or store any credit card or payment account information
  • Purchase records are managed by Apple — view/cancel at Settings → Apple ID → Subscriptions
